# スライドのデザイン（原稿 → 1枚ずつ、プロの決まりで組む）

セミナー資料と営業資料、あわせて250枚あまりを実際に組んだデザイナーが、実物を測って決めた決まりで組む。
決まりを守れば、デザインの経験が無くても、全部の枚が同じ顔の資料になる。

## 0. 始める前に（聞くのは2つだけ）

最初に聞くのは次の2つだけ。会話や原稿から分かっていれば聞かない。

1. **何の資料か・誰に見せるか**（例：元請けへの提案、採用説明会、会社案内、社内の月次の報告）
2. **原稿**：1枚ずつの文。箇条書きやメモでもよい。写真・図・数字があれば、その場所

ほかは、次の既定で組む。組んで見せた後に「色・字の大きさ・会社名やロゴを変えますか」と聞く。

- 見せ方：画面に映して話す資料（大きい字）。手元で読んでもらう資料だと分かれば、そちらにする
- 会社の色：青 #0054FF（グラデは #0000FF → #00BBFF）。会社の色を言われたら、それに替える
- 会社名・ロゴ：言われた物だけ入れる。仮の名前を作らない

原稿がまとまっていなければ、先に「1枚1メッセージ」で枚に分けた原稿を出して、OKをもらってから組む。

## 1. 作る順番（これを守れば崩れない）

1. **その枚は何の話かを決める** → 色が決まる
2. **型を選ぶ**（下の 5.）→ 置く場所が決まる
3. **部品を置く**（字の塊・写真・図・番号）→ 中身が入る
4. **字を大きさの段に乗せる** → 大きさが決まる

## 2. 数字の決まり

### 舞台と地
- 舞台は 1280×720
- 地は2つだけ：**白 #ffffff（既定）**／**少し濃い白 #f1f5f9**（白いカード・写真・グラフを浮かせたい枚）。3つ目は作らない
- 濃い地（紺など）を使うなら、資料の中で1色に決める

### 字の色・書体
- 色は2つ：**濃い黒 #151925**（見出し・主張）／**灰 #4C4F54**（本文の添え・注記）。似た黒は濃い黒にそろえる
- 書体（Google Fonts で読める）：
  - 見出し・主役：Zen Kaku Gothic New 700
  - 本文：画面に映す資料は Zen Kaku Gothic New 700・濃い黒／手元で読む資料は Noto Sans JP 400・灰
  - 数字：DM Sans 700（「STEP1」「Q3」「01」のような英字＋数字の札も丸ごと DM Sans）
  - 16px 以下の添え（注記・出典）：Noto Sans JP・灰。16px より大きい灰の字は Zen Kaku Gothic New
- 和文に混じる英単語は和文と同じ書体。DM Sans は数字だけ

### 字の大きさ（段と倍率）
- 大きさは次の段に乗せる：**8 / 10 / 12 / 14 / 16 / 18 / 20 / 24 / 28 / 30 / 32 / 40 / 45 / 48**。段は増やさない（48 より上は主役と表紙だけで、倍率で決める）
- 倍率をかけて段から外れたら、いちばん近い段に丸める（28×1.4＝39.2 → 40）
- 画面に映す資料の本文は 28px、小さい本文・補足は 20px。題は 40〜48px
- 強調は px でなく倍率で持つ。**×1.2**（和文に混じる数字・英字のなじませ。強調ではない）／**×1.4 強調**／**×2.0 主役**。×1.4 と ×2.0 は独立した1行にだけ使う
- 文の中の語は大きさを変えず、色で立てる。ただし文の中の数字・英字だけは ×1.2（例外は「数字を主役にする」型の枚）
- 1枚の中に **主役／強調／本文／添え** の3〜4段をつくる。同じ大きさが並んでいたら、まだ強弱が読めていない
  - 目安：注記 12〜20px 灰／本文 20〜28px／見出し 30〜48px 黒／結論の数字 42〜56px DM Sans・会社の色

### 行送り・字間
- 行送り：字がある枚は大きさ×1.40、字だけの枚（1メッセージ・つなぎ）は ×2.0
- 字間：見出し・28px 以上の字 0.10em／本文・カードの中 0.02em／数字 −0.05em（数字は和文の字間のままだと空く）
- 字を大きくしたら、行の間も同じ比で広げる

### 色（何の話かで決める）
- **会社の色を1本に決める**：グラデ1本（会社の色の濃い側→明るい側）と、その真ん中の単色
- **強調は既定で単色**。グラデは、その資料の山場（一番伝えたい枚・タイトル・価格・商品名）だけ。10枚の流れに山場は2〜3枚まで
- グラデは1行まるごと（見出し・主役の一言・番号・帯）にだけ使う。文の中の語には単色
- 役割の色は4つに絞る：
  - 会社の色＝肯定・主役・答え
  - 橙 #F47A00＝打ち消し・注記（※）・優先して売りたい物
  - 赤 #FF2D55＝注意・伸びの幅・✕（淡い地はその8%）
  - 黄 #ffea00＝濃い地の上の強調だけ
- **1項目＝1色。** 並べた項目に色を当てたら、番号・帯・見出しの全部でそろえる
- 項目を5つ前後並べて色分けする時は、番号順にこの2色グラデを当てる：①#ff7a18→#fe1d6d ②#3d7cff→#3047d8 ③#ffcf02→#ff6800 ④#25f3d2→#0a88e2 ⑤#f25cff→#7b3dff ⑥#16ff6a→#0090a5。当てるのは番号と帯で、項目名の字は黒

### 線・影・角
- 区切り線は3段：強 #4C4F54 不透明度1.0／中 0.5／弱 0.25
- 影は3つだけ：
  - 字の影：6.76px 14.5px 7px rgba(2,25,91,0.09)。16px より大きい字の全部に付ける。グラデの字は text-shadow だと透けるので `filter: drop-shadow(...)` で付ける
  - カード・面の影：3.54px 3.54px 10px rgba(43,43,43,0.1)
  - 画面に映す資料は、さらに 0 6px 14px rgba(2,25,91,0.16) を1枚足す（白飛びで縁が消えないように）
- 角の丸み：カード 12・吹き出し 10
- 下線：太さ 3px・字の下端 +6px。黒い字の下は会社の色の明るい側（不透明度0.8）、色の字の下はその字と同じ色
- グラデの向き：字は横（90deg）、帯と面は縦

### 約物（句読点・括弧）
- 「、」「。」は半角に詰める。その字だけを `<span style="font-feature-settings:'hwid' 1">、</span>` で包む（字全体にかけるとカタカナまで縮む）
- 行頭の「『 は枠の外へ出す（「 −0.6字／『 −0.54字）。上下の行と字の左端がそろう
- 中央ぞろえの行は、文末の「。」を半角にすると字の塊が真ん中に寄る

## 3. 主役の決め方（1枚に1つ）

1. 2〜3行の枚は、**最後の行（言い切り・答え・結論）が主役**。前の行は前置き。ただし「違う。」のような4字前後の短い言い切りがあれば、位置にかかわらずそれが主役
2. 「それが」「その結果」「つまり」のような前置きの枚は静かに（黒・中くらい）。**次の枚をまるごと主役**にする
3. 1行の中で立てる語は、新しく出た答え・数字・固有名詞のうち1つ。例：「解体工事の工期を、3日短くしました」→ 3日
4. **問いの枚は主役を立てない**（黒のまま）。答えの枚で立てる
5. よくある質問の枚は、聞き手の不安を消す語が主役（大丈夫・無料・いつでも など）
6. 主役の大きさ：独立した行なら前置きの ×2.0（前置き 32 → 主役 64〜72）。主役が独立した1行で4字以下（「違う。」）なら ×3 まで。文の中の語なら大きさは変えず色だけ
7. 項目を並べた枚（番号つき・一覧）は、どれか1つを主役にしない。番号を会社の色でそろえ、題の中の数字（「3つ」）を立てる
8. よくある質問は 5. が優先（答えが2文でも、不安を消す語が主役）

## 4. 判断に迷った時

- **1枚1メッセージ。** 長い文は分けて、字だけの1枚で「間」を作る。1枚に2つ入れると、聞く側が先を読んでしまう
- **全部を立てると、何も立たない。** 「そして」「でも」のようなつなぎの語を1行に立てない
- **同じ言葉は、全部の枚で同じ見え方に。** 会社名・商品名・サービス名の色と書体をそろえる
- **見本や依頼の形は写さず、伝えたいことだけ汲む。** 1枚だけ特別な表現にすると、並べた時に浮く
- **字の塊は、上端でなく縦の中心でそろえる。** 続けて送る同じ流れの枚は、左端もそろえる
- **下に空きが残ったら、字を大きくせず、箱の間や箱の高さで埋める**
- **はみ出したら**：約物を詰める → 列ごとに同じ比で縮める → 箱を高くする、の順
- **写真・画像は切らない**（contain）。枠のほうを写真に合わせる
- **現場の写真・画面は加工しない。** 本物のほうが伝わる
- **伸びを見せるグラフ**は、右上へ上がる線と、始まりと終わりの数字を大きく
- **原稿に無い単位・注記・出典は、作る時に足す。** 「（ここは写真）」のような作り方の指示は字にしない
- **直すのは言われた所だけ。** 良かれと思って他の枚まで広げない

## 6. 出し方

- 1枚ずつ、1280×720 の HTML で出す。全部の枚を1つの HTML に縦に並べ、枚の間に 40px の空きを置く（ブラウザでそのまま見られる）
- 書体は Google Fonts から読む：`Zen+Kaku+Gothic+New:wght@400;700`・`Noto+Sans+JP:wght@400;700`・`DM+Sans:opsz,wght@9..40,700`
- 印刷の時は1枚1ページになるよう `@page { size: 1280px 720px; margin: 0 }` と、枚ごとに `break-after: page` を入れておく（ブラウザの「印刷」→「PDFに保存」で PDF になる）
- 写真は原稿で指定された物を使い、無ければ灰の枠に「写真：〇〇」と書いた仮の箱を置く
- 出した後に、枚ごとに「型・主役・山場かどうか」を1行で添える。直してほしい所を聞く

## 7. 出す前に確かめる

- [ ] 1枚1メッセージになっているか
- [ ] 主役が1枚に1つか。問いの枚で立てていないか
- [ ] 字の大きさが段に乗っているか。強調は ×1.2／×1.4／×2.0 だけか
- [ ] 色は会社の色と役割の4色だけか。グラデは山場の枚だけか
- [ ] 地は白と #f1f5f9 の2つだけか
- [ ] 句読点を半角に詰めたか。行頭の括弧を外へ出したか
- [ ] 写真を切っていないか
- [ ] 同じ言葉が、全部の枚で同じ見え方か
